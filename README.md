# DevPath

DevPath — українськомовний застосунок для самостійного вивчення JavaScript і Python. Почни з навчальної панелі, обери урок, розбери приклади коду й пройди тест. Повернутися до складних запитань можна в розділі «Мої помилки».

## Що є у застосунку

- **Два курси.** У кожному по 10 уроків і 50 запитань. JavaScript охоплює змінні, функції, масиви, DOM, асинхронність і модулі. У Python шлях веде від базових типів і колекцій до обробки файлів, винятків і побудови звіту.
- **Практика з поясненнями.** Кожна відповідь отримує зворотний зв’язок. Чотири правильні відповіді з п’яти завершують урок. Перше успішне проходження дає 100 XP. Баланс і нагороди обчислюються з переліку завершених уроків.
- **Персональний огляд.** На панелі видно наступний урок, відсоток проходження кожного курсу, серію днів навчання й досягнення. До активності зараховується перевірена відповідь у тесті або під час повторення.
- **Повторення помилок.** Неправильна відповідь потрапляє до списку. Під час повторення правильна відповідь відкриває дію «Позначити як опрацьоване».
- **Локальний прогрес.** Тема й результати зберігаються у браузері. У налаштуваннях можна експортувати JSON, відновити його на іншому пристрої або підтвердити скидання. Для навчання не потрібні реєстрація, ключі чи серверний API.

## Локальний запуск

Потрібен Node.js версії 22.12 або новішої з npm. Відкрий термінал у папці з `package.json`.

```sh
npm ci
npm run dev
```

Відкрий адресу, яку Vite виведе в терміналі, зазвичай `http://localhost:5173`. Зміни у вихідних файлах з’являтимуться під час роботи. Для зупинки натисни Ctrl+C. У Windows PowerShell можна використовувати `npm.cmd` замість `npm`.

## Тести та production-збірка

| Команда | Результат |
| --- | --- |
| `npm test` | Один запуск усіх автоматизованих тестів Vitest |
| `npm run test:watch` | Повторний запуск тестів після змін у коді |
| `npm run build` | Перевірка типів TypeScript і збірка статичних файлів у `dist/` |
| `npm run preview` | Локальний HTTP-перегляд останньої збірки, зазвичай на `http://localhost:4173` |

Після зміни вихідного коду повтори збірку перед перевіркою через `preview`. Для швидкої ручної перевірки пройди перший урок із однією помилкою, онови сторінку й відкрий «Мої помилки». На огляді має бути 100 XP, а у списку повторення — одне запитання.

## Розгортання на Vercel

1. Додай вихідні файли разом із `package-lock.json` і `vercel.json` до свого Git-репозиторію та надішли зміни у віддалений репозиторій.
2. Створи новий проєкт у Vercel, імпортуй репозиторій і вибери коренем папку з `package.json`.
3. Використай пресет **Vite**, команду встановлення `npm ci`, команду збірки `npm run build` і папку результату `dist`. Вибери підтримувану версію Node.js, сумісну з `engines` у `package.json`. Змінні середовища для цієї версії не потрібні.
4. Натисни **Deploy**. Відкрий видану адресу, перейди на `/courses/javascript/js-variables` й онови сторінку. Правило в `vercel.json` повертає `index.html` для прямих переходів на маршрути React Router. [Документація Vercel для Vite](https://vercel.com/docs/frameworks/frontend/vite)

Локальний сайт і сайт на Vercel мають окремі сховища браузера. Щоб перенести результати, експортуй прогрес у налаштуваннях локальної версії й імпортуй файл на опублікованій.

## Структура проєкту

```text
public/          Ілюстрації та favicon, які потрапляють у збірку
src/
  main.tsx       Точка входу, BrowserRouter і провайдер прогресу
  App.tsx        Таблиця маршрутів
  components/    Навігація, картки, нагороди та спільні елементи сторінок
  pages/         Огляд, курси, уроки, повторення, досягнення та налаштування
  data/          Каталог і окремі модулі уроків JavaScript та Python
  types/         Контракти курсів, запитань і збереженого прогресу
  domain/        Оцінювання, XP, умови нагород і зміни стану прогресу
  services/      Валідація JSON та адаптер localStorage
  hooks/         Доступ компонентів до спільного стану через useProgress
  styles/        Кольори тем, типографіка, навігація та панель навчання
  utils/         Робота з календарною датою і серією навчання
tests/           Перевірки каталогу, навчальної логіки та збереження
```

Почни з маршруту першого уроку і простеж шлях даних від відповіді до збереження. Це розібрано в [ARCHITECTURE.md](./ARCHITECTURE.md). Для практичних змін — додавання курсу, уроку, запитання, нагороди, сторінки або бекенду — скористайся [DEVELOPMENT_GUIDE.md](./DEVELOPMENT_GUIDE.md).
